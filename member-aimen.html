  • Build advanced React and Next.js applications with TypeScript.
  • Improve accessibility, responsive layouts, performance, and design-system thinking.
  • Practice automated testing with Jest, React Testing Library, Playwright, and API testing.
  • Use code reviews, documentation, Git workflows, and clean architecture consistently.

2. Develop research skills through my master's degree

  • Learn how to read, compare, and critically evaluate research papers.
  • Develop skills in research methodology, problem definition, experiment design, and academic writing.
  • Work with datasets, reproduce relevant studies, and communicate results through clear visualizations.

  • Build foundations in Python, statistics, linear algebra, data preprocessing, and model evaluation.

  • Use tools such as scikit-learn, PyTorch, vector databases, and responsible AI practices.

4. Integrate AI with scalable web systems

  • Design secure APIs that connect frontend products to AI and machine learning services.
  • Learn deployment, Docker, cloud services, monitoring, caching, and database optimization.
  • Build portfolio projects such as an AI learning assistant, research dashboard, or personalized career platform.
  • Measure usability, accuracy, latency, cost, privacy, and accessibility before release.
